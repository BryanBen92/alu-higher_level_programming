Printing a sorted view preserves the original order.

    >>> MyList = __import__("1-my_list").MyList
    >>> values = MyList([3, -1, 3, 0])
    >>> values.print_sorted()
    [-1, 0, 3, 3]
    >>> values
    [3, -1, 3, 0]
    >>> MyList().print_sorted()
    []
    >>> MyList([5]).print_sorted()
    [5]
